# 家庭帳號與共用家事設定

目前網站在未設定 Firebase 時提供單機體驗；本機儲存的任務完成狀態無法同步給其他手機。

1. 建立 Firebase 專案和 Web App，複製 Web App 的公開設定物件到 `firebase-config.js`，替換 `null`。不要放入服務帳號私鑰。
2. 在 Authentication 啟用「電子郵件／密碼」登入。
3. 建立 Cloud Firestore 資料庫，將 `firestore.rules` 的內容發佈到 Firestore 規則。
4. 在 Authentication 的授權網域中加入 `mvpwilliam.github.io`，重新部署網站。
5. 每位家人各自建立帳號，填入同一組不易猜到的家庭代碼。代碼是共用空間識別字，不應當作帳號密碼。

遊戲日以 UTC 整點作為分界（台灣時間也在每個整點切換）。完成家事使用 Firestore 交易和唯讀完成紀錄，兩人同時操作只有一人能成功；安全規則以伺服器時間限制只能寫入當前的一小時。

這是家庭原型：知道家庭代碼且有帳號的人可以讀取該家庭資料。正式開放公開註冊前，應增加家庭邀請／成員權限與管理任務的權限區分。
